# To-Do List Application (Python)

A simple CLI-based To-Do List application built using Python.

## Features
- Add new tasks
- View all tasks
- Delete tasks
- Data persistence using JSON file handling

## Concepts Used
- Lists
- Loops
- Conditional statements
- Functions
- File handling (JSON)

## How to Run
1. Download the `todo_list.py` file
2. Run the program using:
   python todo_list.py

## Note
The `tasks.json` file will be created automatically when tasks are added.
